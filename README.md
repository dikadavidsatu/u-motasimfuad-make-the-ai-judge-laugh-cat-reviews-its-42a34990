One-star cat review for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty. A single original review — the cat grants its human one star: he calls it "his house", but the cat decides when the door opens, when the food appears, and when he sleeps; he just pays the rent. The program writes the review (134 characters, one line) to `/output/entry.txt`, validating it against the competition gate (1–200 characters, not only whitespace, single line) and reading it back to confirm exactly what was written.

## Run it

```sh
node main.ts
```
